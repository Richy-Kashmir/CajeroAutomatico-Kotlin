# Cajero Automático en Kotlin

Pequeña aplicación de consola desarrollada en Kotlin que simula el funcionamiento básico de un cajero automático.

## Funcionalidades

- Consultar saldo disponible.
- Ingresar dinero en la cuenta.
- Retirar dinero de la cuenta.
- Validación de opciones del menú.
- Control de errores en ingresos y retiradas.
- Salida segura del programa.
